# 🍊 กินไรดี

แอป Vue 3 สุดทันสมัยที่เกิดมาเพื่อแก้ปัญหาโลกแตกที่ว่า "วันนี้กินไรดี" ตัวแอปจะช่วยให้เราค้นหาสูตรอาหาร หาร้านอาหารใกล้ตัว จัดการของในตู้เย็น และแนะนำเมนูอาหารจากวัตถุดิบที่เรามีอยู่ โปรเจกต์นี้ตั้งใจทำ UI ให้ออกมาดูพรีเมียม ใช้งานลื่นไหล และรองรับหน้าจอทุกขนาด

---

## ฟีเจอร์หลัก

### 1. ระบบ Routing หน้าหลัก 6 หน้าและหน้า 404

แอปพลิเคชันมีระบบ Routing ที่ครอบคลุม โดยมีหน้าหลักและระบบจัดการเมื่อเข้าผิดลิงก์ตามนี้:

- **Landing Page `/` :** หน้าแรกที่แนะนำฟีเจอร์ต่างๆ ของแอป มีแอนิเมชันตอนเลื่อนจอและปุ่มเปิดปิดโหมดมืด
- **หน้ากินไรดี `/kinraidee` :** ระบบสุ่มอาหารสไตล์ตู้สล็อต พร้อมตัวกรองที่ปรับแต่งได้แบบละเอียด
- **หน้าร้านอาหารใกล้ฉัน `/restaurants` :** ค้นหาร้านอาหารตามเมนูที่อยากกิน สามารถกรองระยะทางและคะแนนรีวิวได้
- **หน้าตู้เย็นของฉัน `/myfridge` :** ระบบจัดการวัตถุดิบในตู้เย็นแบบครบวงจร
- **หน้าทำไรดี `/tumraidee` :** ระบบแนะนำสูตรอาหารโดยอิงจากวัตถุดิบที่เรามีอยู่ในตู้เย็น
- **หน้ารายละเอียดสูตรอาหาร `/recipe/:id` :** Dynamic Route ที่แสดงวิธีทำอาหารแบบทีละขั้นตอน
- **หน้า 404 ไม่พบเพจ `/:pathMatch(.*)*` :** หน้าดักจับ URL ที่ไม่มีอยู่ในระบบ

### 2. ระบบ CRUD แบบครบวงจร

- **ตู้เย็นของฉัน:** เพิ่ม ดู แก้ไข และลบวัตถุดิบได้ มีปุ่มกดยืนยันก่อนลบเพื่อป้องกันการเผลอกด
- **สูตรอาหารของคุณ:** ผู้ใช้สามารถเพิ่ม แก้ไข และลบสูตรอาหารของตัวเองได้ที่หน้าทำไรดี

### 3. การจัดการ State และความสัมพันธ์ของข้อมูล

- **Shared State:** ใช้ State ตรงกลางสำหรับเก็บข้อมูลวัตถุดิบและสูตรอาหาร เพื่อให้ข้อมูลอัปเดตตรงกันทุกหน้าโดยไม่ต้องรีเฟรช
- **การเชื่อมโยงข้อมูล:** ระบบจะนำวัตถุดิบในตู้เย็นไปจับคู่กับวัตถุดิบที่ต้องใช้ในสูตรอาหาร เพื่อบอกว่าเมนูไหนทำได้เลย หรือเมนูไหนขาดของอีกแค่ 1 ถึง 2 อย่าง

### 4. ฟอร์มและระบบตรวจสอบข้อมูล

ตัวแอปมีฟอร์มหลัก 2 ฟอร์มที่ตรวจข้อมูลอย่างเข้มงวด:

- **ฟอร์มจัดการวัตถุดิบ:** ตรวจสอบช่องที่บังคับกรอก ป้องกันการพิมพ์ชื่อซ้ำ ตรวจเช็กว่าจำนวนต้องเป็นค่าบวก และวันหมดอายุต้องไม่เป็นวันในอดีต
- **ฟอร์มจัดการสูตรอาหาร:** ตรวจสอบชื่อ คำอธิบาย การอัปโหลดรูปภาพ และต้องมีวัตถุดิบกับขั้นตอนการทำอย่างน้อย 1 รายการถึงจะบันทึกได้

### 5. ประสบการณ์ใช้งานและดีไซน์

- **ความสม่ำเสมอของดีไซน์:** คุมโทนสีส้มและขาวให้เป็นเอกลักษณ์เดียวกันทั้งแอป
- **การแสดงสถานะระบบ:** มีหน้าโหลด หน้าข้อมูลว่าง และแจ้งเตือน Error อย่างชัดเจน
- **รองรับทุกหน้าจอ:** ออกแบบมารองรับทั้งหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์
- **Dark Mode:** รองรับโหมดมืดที่เปลี่ยนสีได้เนียนตา

## Tech Stack ที่ใช้

- **Frontend Framework:** Vue 3 ใช้ Composition API แบบ `<script setup>`
- **Styling:** Tailwind CSS v4 เขียนแบบ Utility ล้วน ไม่มี CSS เก่าปน
- **Routing:** Vue Router
- **Build Tool:** Vite
- **ระบบเก็บข้อมูล:** เก็บผ่าน localStorage ผสมกับ Reactivity ของ Vue เป็น Shared State

## การติดตั้งและรันโปรเจกต์

### สิ่งที่ต้องมี

- Node.js แนะนำเวอร์ชัน 20 ขึ้นไป
- npm ซึ่งปกติจะติดมากับ Node.js อยู่แล้ว

### ขั้นตอนการติดตั้ง

1. **โคลนโปรเจกต์:**

   ```bash
   git clone [https://github.com/GodzK/INT250-G04-spongebob-Kinraidee.git](https://github.com/GodzK/INT250-G04-spongebob-Kinraidee.git)
   cd INT250-G04-spongebob-Kinraidee
   ```

2. **ติดตั้ง Dependencies:**

   ```bash
   npm install
   ```

3. **รันเซิร์ฟเวอร์:**

   ```bash
   npm run dev
   ```

   เมื่อรันเสร็จสามารถเปิดเบราว์เซอร์แล้วเข้า URL ที่ขึ้นใน Terminal ได้เลย ปกติจะเป็น http://localhost:5173

4. **บิลด์โปรเจกต์เพื่อนำไปใช้งานจริง:**
   ```bash
   npm run build
   ```

## วิธีการใช้งาน

### 1. วิธีเพิ่มและจัดการวัตถุดิบ

1. ไปที่หน้า **ตู้เย็นของฉัน**
2. กดปุ่ม **เพิ่มวัตถุดิบ**
3. ลองกรอกข้อมูลดู สามารถลองเว้นว่างหรือใส่วันที่ย้อนหลังเพื่อดูระบบ **Validation** ได้เลย
4. พอกดเซฟ ข้อมูลจะไปโชว์เป็นการ์ดในตู้เย็น โดยมีสีขอบบอกสถานะความสด สีเขียวคือสด สีเหลืองคือใกล้หมดอายุ และสีแดงคือหมดอายุแล้ว
5. กดไอคอนจุดสามจุดบนการ์ดเพื่อแก้ไขหรือลบวัตถุดิบได้ เวลากดลบจะมีหน้าต่างเด้งขึ้นมาถามเพื่อยืนยันอีกครั้ง

### 2. วิธีใช้งานระบบแนะนำสูตรอาหาร

1. ไปที่หน้า **ทำไรดี**
2. แอปจะอ่านข้อมูลของในตู้เย็นมาให้เลย ถ้าตู้เย็นว่างเปล่า ระบบจะโชว์หน้าข้อมูลว่าง เพื่อบอกให้เราไปเพิ่มของก่อน
3. ลองเพิ่มของในตู้เย็นดู เช่น ไข่ และ ข้าว
4. พอกลับมาที่หน้าทำไรดี จะเห็นเมนูอาหารขึ้นมาในหมวด **พร้อมปรุงทันที** หรือหมวด **เกือบพร้อมแล้ว** ถ้ายืนยันว่าขาดของอีกแค่ 1 ถึง 2 อย่าง
5. กดดูรายละเอียดสูตรอาหาร หรือกดปุ่ม **ทำอาหารเลย** เพื่อให้ระบบหักวัตถุดิบออกจากตู้เย็นอัตโนมัติ

### 3. วิธีใช้งานระบบสุ่มอาหาร

1. ไปที่หน้า **กินไรดี**
2. เลือกเงื่อนไขอาหารที่แถบด้านซ้าย เช่น อาหารฮาลาล วีแกน หรือไม่ทานเนื้อสัตว์
3. กดปุ่มหมุนเพื่อสุ่มอาหาร
4. พอผลลัพธ์เด้งขึ้นมา เราจะกดสุ่มใหม่ หรือกดหาร้านอาหารที่ขายเมนูนั้นเลยก็ได้

## การจัดการ State และบันทึกข้อมูล

ตัวแอปจำลองการทำงานเหมือนมีระบบหลังบ้านโดยใช้ API ของเบราว์เซอร์:

- **ความรวดเร็วในการแสดงผล:** จัดการ State ส่วนกลางด้วย `ref` และ `watch` ของ Vue แยกไฟล์ไว้ชัดเจน
- **การบันทึกข้อมูล:** ทุกครั้งที่เพิ่ม ลบ หรือแก้ไขวัตถุดิบและสูตรอาหาร ข้อมูลจะถูกเซฟลง `localStorage` อัตโนมัติ รีเฟรชหน้าหรือปิดเบราว์เซอร์ข้อมูลก็ไม่หาย
